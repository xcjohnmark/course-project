# Course Project

A modern, responsive "Coming Soon" landing page ready to deploy instantly on [Vercel](https://vercel.com).

## Deployment on Vercel

1. Go to [Vercel](https://vercel.com/new).
2. Import this repository (`https://github.com/xcjohnmark/course-project`).
3. Click **Deploy** (no build settings or frameworks needed; it automatically serves `index.html`).
